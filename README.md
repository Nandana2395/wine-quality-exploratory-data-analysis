# Wine Quality Exploratory Data Analysis (EDA)

## Overview
This project performs Exploratory Data Analysis (EDA) on the Wine Quality dataset from the UCI Machine Learning Repository. The objective is to understand how different physicochemical properties influence wine quality through data preprocessing, visualization, statistical analysis, and feature relationships.

## Dataset
- Source: UCI Machine Learning Repository
- Red Wine Samples: 1,599
- White Wine Samples: 4,898
- Total Samples: 6,497
- Features: 11 physicochemical properties
- Target Variable: Quality

## Project Objectives
- Load and preprocess the dataset
- Perform univariate and comparative analysis
- Study correlations between features
- Analyze factors affecting wine quality
- Detect outliers using IQR and Z-score methods
- Perform statistical hypothesis testing
- Explore advanced feature relationships

## Key Insights
- Alcohol shows a positive relationship with wine quality.
- Volatile acidity is negatively correlated with quality.
- White wines generally contain higher residual sugar and sulfur dioxide.
- Several physicochemical features contain significant outliers.
- Statistical tests confirm differences between red and white wines.
